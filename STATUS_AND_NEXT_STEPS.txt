2. Services Implemented:
   - FirebaseService (lib/core/services/firebase_service.dart):
     Dual-mode engine. Enables Firestore offline persistence with unlimited cache. Gracefully falls back to local offline engine if Firebase credentials are not yet configured.
   - AuthService (lib/core/services/auth_service.dart):
     Full authentication suite including:
     - Anonymous Authentication (zero-friction guest mode).
     - Email & Password Signup and Login.
     - Account Linking (upgrades anonymous accounts to permanent email credentials preserving existing workouts, routines, and logs without data loss).
     - Password Reset and Account Deletion.
     - Role-Based Access Control (RBAC) via Firebase Custom Claims (request.auth.token.admin == true).
   - FirestoreService (lib/core/services/firestore_service.dart):
     Implements user-owned Firestore hierarchy:
       users/{uid}/profile/info
       users/{uid}/workouts/{workoutId}/exercises/{exerciseId}/sets/{setId}
       users/{uid}/routines/{routineId}/exercises/{exerciseId}
       users/{uid}/customExercises/{exerciseId}
       users/{uid}/settings/preferences
     Complete CRUD, indexed date ordering, and subcollection management.
   - WorkoutAutosaveService (lib/core/services/workout_autosave_service.dart):
     Continuous background autosave for active workouts via SharedPreferences. Crash recovery on app restart.
   - BackupService (lib/core/services/backup_service.dart):
     Versioned (v1.0) JSON backup generator and validator. Includes schema validation, type checks, and duplicate-prevention importer.

3. Workout Logging, Catalogue & Analytics:
   - Unlimited sets with dynamic set types: Normal, Warm-up (W), Drop Set (D), Failure (F).
   - Reps in Reserve (RIR) per set.
   - Support for Weighted, Bodyweight, and Weighted-Bodyweight exercises.
   - Dynamic Carry-over: queries real previous workout logs to display exact previous performance (e.g. 40 kg x 10 reps).
   - Real-time sync status indicators: 'Saved Locally', 'Waiting for Sync', 'Synced', 'Sync Failed'.
   - Complete 8-category exercise catalogue: Chest, Back, Shoulders, Biceps, Triceps, Legs, Core, Full Body.
   - Custom exercise creation, editing, and deletion.
   - Full routine builder with planned sets, target reps, planned weights, and reordering.
   - Real progress analytics: Weekly volume spline curves, weight trend, and dynamically calculated Personal Records (PRs).
